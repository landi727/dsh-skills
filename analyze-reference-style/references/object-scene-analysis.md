# Object and Scene Analysis

Keep content description independent from the global style analysis. Analyze what is depicted and how it is visually presented without allowing object names to substitute for visible description.

## Object inventory

Group repeated or tightly connected objects when that better reflects the composition. For every important object or group, cover:

| Field | Required analysis |
|---|---|
| Identity | What can be identified; mark ambiguity rather than guessing |
| Position | Relative horizontal and vertical placement within the frame |
| Scale | Approximate visual size and relationship to nearby objects |
| Silhouette | Basic construction, contour, orientation, and irregularity |
| Color | Main, secondary, and accent colors as visibly presented |
| Internal detail | Lines, patches, patterns, highlights, texture, and their density |
| Abstraction | Degree and manner of realism, simplification, distortion, or symbolization |
| Layer and overlap | What it covers, what covers it, and how depth is established |
| Boundary | Whether it touches or is cropped by the frame |
| Role | Visual anchor, counterweight, connector, scale cue, accent, or background support |
| Style manifestation | How it expresses the already-established global visual system |

Use approximate positional language or normalized regions only when useful. Do not invent exact coordinates.

## Scene structure

After the inventory, explain:

- background, middle-ground, and foreground layers, if those categories apply;
- the overlap network among major masses;
- pathways, sightlines, or repeated forms that connect regions;
- scale contrasts and spatial contradictions;
- where content density increases or decreases;
- how objects interact with negative space and the frame.

If conventional layers do not apply, describe the actual organizational logic instead, such as a flat field, diagram, collage, grid, radial system, or floating inventory.

## Separation rules

- Do not place object counts, names, clothing, food types, or positions inside the global style definition.
- Do not use a style label as a substitute for object-specific color, shape, detail, or overlap.
- Distinguish “the image uses simplified forms globally” from “this cabbage consists of several large green patches.”
- Mention an object's contribution to style only after describing its visible presentation.
- Do not infer hidden sides, off-frame content, narrative causality, or object identity without evidence.

## Multiple images

When several reference images are supplied:

- inventory each image independently before identifying shared content patterns;
- distinguish recurring style treatment from recurring subject matter;
- do not treat a repeated object as proof of a shared style mechanism;
- identify common object-presentation rules only when multiple examples visibly support them.
