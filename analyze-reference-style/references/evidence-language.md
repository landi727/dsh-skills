# Evidence and Language Rules

## Separate three levels of claim

### Visible fact

Report what can be directly inspected: position, shape, color relationship, line behavior, cropping, overlap, texture, or shadow.

Example:

> The object is bounded by a thin dark contour, while its interior is a single orange field with one separate pale highlight shape.

### Interpretation

Explain how visible facts operate visually.

Example:

> Because the highlight is a discrete shape rather than a tonal transition, it preserves the object's graphic flatness instead of modeling rounded volume.

### Inference

Mark claims about production process, date, movement, influence, author intention, or model behavior as uncertain unless independently known.

Example:

> The grain may evoke printed ink on paper, but the image alone does not establish whether it was physically printed or digitally simulated.

Never promote an inference into a visible fact through confident wording.

## Description before labels

- Describe the visual evidence before using a style label.
- Use labels only as shorthand after the image has been explained.
- Avoid stacking loosely related terms to create authority.
- If a label adds no explanatory value, omit it.

Bad:

> This is a 1970s risograph, naïve, psychedelic, editorial illustration.

Better:

> The image uses large flat color fields, thin contours, compressed space, and low-contrast grain. These features may evoke some historical editorial-print aesthetics, but the production method and date cannot be confirmed from the image.

## Explain absence as a system

Do not stop at negative statements such as “no light,” “no perspective,” or “no detail.”

Explain:

- which expected cues are absent or reduced;
- what visible devices replace them;
- whether the reduction is consistent;
- what effect the replacement produces.

## Avoid false precision

- Do not assign percentages, pixel widths, dates, color codes, or confidence scores unless they are measured and materially useful.
- If a measurement is approximate, say so.
- Do not assume a model can execute a measured value merely because the value can be observed.
- Do not convert qualitative visual judgments into arbitrary numeric ratings.

## Avoid repetition and ornamental detail

- Include a statement only if it records evidence, explains a mechanism, distinguishes alternatives, or establishes an important relationship.
- Do not repeat the same observation under color, light, texture, and atmosphere unless each section adds a distinct causal explanation.
- Do not list every visible minor object when grouping better explains the scene.
- Do not force every dimension to the same length.

## Use proportional verification

Verify a claim only when an error would materially alter:

- the overall visual judgment;
- a decisive style mechanism;
- an important object relationship;
- a comparison conclusion.

Do not browse, sample colors, count edges, or create crops by default. Use them when direct inspection leaves a consequential question unresolved.

## Maintain analytical tone

- Treat the user's description and prior attempts as evidence, not as something to defeat.
- Correct earlier claims directly when new evidence contradicts them.
- Do not blame prompt quality for model behavior without comparing actual outputs.
- Do not present speculation with an expert-performance tone.
- State limits plainly.

## Final self-check

Before responding, confirm:

- Every required dimension was considered.
- The most style-defining dimensions received the deepest analysis.
- Visible facts are distinguishable from interpretation and inference.
- Global style and object/scene description remain separate.
- The decisive mechanisms are supported by specific image evidence.
- No medium, decade, movement, artist, or intention was asserted without support.
- No prompt, generation advice, or production prescription was added unless separately requested.
