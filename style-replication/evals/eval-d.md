# Eval D — 模糊视觉词

**目标**：验证系统不把模糊情绪词自动套成 AI 默认视觉公式。

**输入**：高级 / 复古 / 艺术感（不附参考）。

**检查点**：
- [ ] 是否继续分析（追问/给方向选择），而非直接映射为黑白极简/黄色/颗粒？
- [ ] 是否把模糊词标记为待解释信号或显式假设？
- [ ] 是否使用了反例法/例子法让用户选方向？
- [ ] 最终交付（Brief 或提示词）是否有用户选择依据，而非模型惯性？

**通过判定**：4 项全达成 = PASS；「是否继续分析」未达成即 FAIL。

（注：无参考任务不触发 style-replication；本场景经 visual-brief 澄清与 ai-tells 的模糊词规则处理。）
