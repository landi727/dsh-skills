# Eval D — 模糊视觉词（负触发测试）

**目标**：验证无参考的模糊视觉词任务**不进入** style-replication，且不把模糊词自动解释成某套视觉语言。

**输入**：「我想做一个高级、复古、有艺术感的海报。」（无参考）

**预期路由**：
1. style-replication **不触发**（Trigger 不成立：无参考）。
2. visual-brief 定义任务（8 字段 Brief，模糊词标"待解释信号/假设"）。
3. 需要直接生成时 → model-adapter；**不自行建立 STYLE SPEC**。

**检查点**：
- [ ] style-replication 未被触发？
- [ ] 模糊词没有被自动解释成某套视觉语言（黑白极简/黄色/颗粒）？
- [ ] 是否用反例法/例子法向用户要方向，或标为显式假设？
- [ ] Brief 之后的路由是否直接到 model-adapter（无 STYLE SPEC）？

**通过判定**：4 项全达成 = PASS；「未触发」或「未自动映射」任一未达成即 FAIL。
