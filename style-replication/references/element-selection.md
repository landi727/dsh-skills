# Element Selection · 领域差异速查（style-replication 附属）

生成新元素前先问"**为什么这个元素属于当前作品？**"，再按领域对照惯性元素。

## 插画

人物 / 道具 / 环境 / 叙事物件——每个物件要承担叙事或氛围职责，不画"凑热闹"的角色。

## 影视概念

世界构成元素——地标、建筑、机械、生态要来自该世界的设定逻辑，不是通用科幻道具库。

## 平面

字体 / 图形 / 图片 / 符号——服务信息层级与版面逻辑，不堆装饰。

## UI

Component / Icon / Container / Navigation / Visual Vocabulary——来自产品内容与真实交互语境，拒绝无关装饰组件。

## 通用 AI 惯性元素（优先拒绝）

无意义漂浮物、模板化构图物件、套路场景、与概念无关的"丰富画面"、与视觉世界无关的惯性元素。
