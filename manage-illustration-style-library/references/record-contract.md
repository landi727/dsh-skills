# 归档与选择约束

沿用库中当前字段和枚举值；以下规定语义，不创建第二套索引结构。字段确需扩展时保持旧条目可读，并同步入口说明。

## 条目必须表达的信息

| 信息组 | 最少保留内容 |
| --- | --- |
| 身份与版本 | 稳定编号、名称、整理日期、旧版本身份或版本记录；原分析日期未知时留空 |
| 参考图 | 原文件名、持久文件标识、作用；多张参考逐张对应；可用时保留哈希与缩略预览 |
| 分析来源 | 完整报告或蓝图的持久标识、明确对应关系、原分析与本次补充的边界 |
| 可迁移规则 | 有依据的形体、线条、填色、配色关系、空间、肌理、疏密；固定规则、可变范围、跑偏征兆 |
| 原图内容 | 主体、道具、情节和构图实例；不得默认带入新主题 |
| 适用条件 | 用途、情绪、复杂度、文字量、画幅和制作限制；推断与已验证用途分开 |
| 独立状态 | 来源完整度、分析核验、生图验证、用户评价，分别记录依据和范围 |
| 关联记录 | 生成样例、反馈出处、变更原因、冲突或待补材料 |

未知内容留空并说明缺口，不为完整填表创造证据。单图分析须标明样本有限；跨主体、跨媒介适用性未经实际使用就保留为推断。

## 证据门槛

- **可自动匹配**：实际原图可读，完整分析可读，二者明确配对，当前规则经核查且无未解冲突。是否生图验证另记。
- **待补**：只剩摘要、缺原图、无法核实配对、只有历史线索或存取失败。保存真实已有内容与检索记录，自动选择标记为否。
- **冲突或撤回**：保留材料和用户明确范围；除非能明确分离仍有效规则，否则排除自动选择。

附件标识、报告内引用或可复核的内容对应关系可支持配对；相近日期、同类题材、相似文件名只提供检索线索。

## 更新完整性

1. 写入前读取当前目标身份和版本；对已有文件使用替换流程。
2. 原图及分析无改动时复用原标识；条目变更保留稳定编号，索引只保存筛选和导航所需信息。
3. 先保存来源和条目，最后更新索引；失败部分不对外宣称可用。
4. 同一风格不同作品合并成风格族须有绘画规则依据，同时保留每张图的分析和例外。
5. 验收以真实取回为准：从索引定位条目，能读出完整分析与原图，并解释适合及不适合的需求。只读检查不生成图片。
