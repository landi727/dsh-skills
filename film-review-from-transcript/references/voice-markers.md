# Voice Markers（声音特征提取清单，三层）

从输入材料提取三层，每层带原句示例（Step 2 用）：

## 1. Thought Signature（思考特征）—— 必须保留

- **判断方式**：怎么下结论（先举例再总结？先抛结论再找补？）。
- **犹豫与自我修正**："可能吧 / 我说不好 / 一开始我以为……后来发现不对"——是作者思考的痕迹。
- **观点力度**：强断言（"就是""根本不是"）vs 缓冲（"有点""蛮"），强弱分布本身就是个性。
- **矛盾与变化**：立场随观影过程变化的过程。

## 2. Authorial Voice（作者声音）—— 保留并适度书面化

- **词汇指纹**：用户反复用的实义词、专有说法、个人比喻。
- **句式节奏**：长短句习惯、设问自答、连词偏好（但是/然后/就）。
- **表达偏好**：爱用反问、爱举具体场景、爱下私人判断。

## 3. Speech Noise（口述噪声）—— 默认清理

- 填充词："就那个 / 然后然后 / 反正就是 / 哦对"
- 口吃与转录断裂："就是就是""那个那个"
- 自我插话："我可能讲得乱七八糟的""我先说啊"
- **口语脚手架**："我觉得 / 我会觉得 / 我有一个非常大的感受 / 这也是我特别强烈的感受 / 对的"——书面成稿默认删除并转直接断言；作者的判断姿态由断言本身呈现，不需要"我觉得"来标记。

（说明：口语脚手架一度被误归入 Thought Signature 导致"口屁"残留——真实生产反馈后修正。判断姿态 ≠ 判断的标记词。）

## 提取要求

- **高价值原句清单**：有分量、有画面感、有个人判断的句子 → 尽量原样保留（属于 Authorial Voice 的最强样本）。
- **反指标（禁用语）**：用户不用的词 + AI 高频词（见 `anti-ai-patterns.md`）。

原则：Voice Profile 描述"**这个用户怎么想、怎么说**"，不是"标准中文怎么写"。成稿允许书面化（清理第三层、打磨第二层），不允许统一化（消灭第一层、重写第二层）。
