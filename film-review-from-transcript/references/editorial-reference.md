# Editorial Reference（《人物》× 看理想 编辑机制，v0.2 用）

记录**可复用的编辑机制**，不复制任何具体文风、句式、标题模板或品牌口吻。来源：[《人物》主笔谢梦遥谈特稿开头](https://www.sohu.com/a/287941626_375507)、《人物》特稿叙事策略研究、《如何写影评》相关笔记与看理想公开评论文章的一般性特征。

## 从《人物》吸收（材料与克制）

1. **从具体处进入**：开头从一个人、一个动作、一个场景、一个细节开始，不从抽象判断开始。抽象判断可以早出现，但必须挂在具体材料上。（此为特稿机制——**影评开头不套用**，见下方"影评开头"。）
2. **让材料承担表达**：事实、原话、细节自己说话；作者少替材料总结。能用一句台词、一个镜头说明的，不用形容词。
3. **作者语言克制**：不为了"文采"制造腔调；比喻只在必要时出现，且来自材料自身。
4. **结构跟随材料关系**：不是按主题分类排材料，而是让材料之间的联系决定顺序。
5. **小切口、可查证**：每个判断能指出它来自作品的哪里（场景/台词/行为/形式处理/原作差异）。

## 从看理想吸收（问题与推进）

1. **一条主导主线**：全文围绕一条真正值得讨论的主线展开——可以是一个问题、一个矛盾、一个核心判断、一个未解决的冲突；**允许多个独立观察存在，只要它们受到主线控制**。材料本身松散时，不强行收束出一个假中心。
2. **判断落到作品内部**：不空谈主题；每个判断必须回到具体的场景、台词、人物行为、形式选择。
3. **观点之间产生下一步**：上一段的结论是下一段的起点——"一个判断 → 为什么 → 作品具体做了什么 → 这意味着什么 → 获得了什么 → 付出了什么 → 下一个问题"。
4. **从细节进入更大的问题**：先写作品里的具体细节，再由细节引向更大的议题，而不是先立论再找例子。
5. **小标题承担论证推进**：存在小标题时，标题应是判断或问题的推进（"它怎么立住的"），禁止资料分类式标题（"配乐/摄影/主题"）。
6. **保留疑问**：矛盾、犹豫、未解决的问题是文章的合法终点；不必强行合上。

## 影评开头：四种同等级入口（由材料决定）

1. 强判断（例："诺兰把《奥德赛》里奥德修斯最不堪的那一面删掉了。"）
2. 具体场景
3. 核心矛盾
4. 真正的问题

影评与特稿不同，判断式开头常常更好；不要固定优先场景开头。

## 两类机制如何合并使用

- 论证骨架（问题/层级/推进）用看理想机制；
- 段落内的血肉（细节、原话、克制）用《人物》机制；
- 判断强度与证据关系用本 skill 的 Claim Strength Check 约束。

## 禁止清单

- 禁止复制任何一篇具体文章的结构或开头；
- 禁止模仿品牌口吻（"看理想体""人物体"）；
- 禁止把这两家的机制当成"更高档的模板"——机制服务于当前材料，不反过来。
