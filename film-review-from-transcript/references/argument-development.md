# Argument Development（论证发展规则，v0.3）

## 四类发展（U + R → D）

1. **Clarification（说准确）**：把模糊感受说准确。例："神被淡化"→"神作为角色被淡化，神性被重新分配到海、法则和命运"。
2. **Connection（找关系）**：找到用户几个独立观察之间的隐藏关系。例：英雄主义宣传 + 配角工具化 → "英雄叙事越成功，他者越扁平"。
3. **Deepening（推一层）**：沿原判断再推进一层。例："他要承受惩罚"→"有能力赢却接受规则作用在自己身上，才是英雄主义最强处"。
4. **Tension（找反面）**：发现原观点内部的矛盾、代价或反面。例："删掉不堪"×"罪疚煎熬"→"删掉的是卑劣行为，不是罪的重量"。

## 允许 AI 主动挑战作者

研究发现明显反证时**必须保留**，处理流程：

```
作者观点 → 支持材料 → 反例/矛盾 → 重新校准判断强度
```

- 校准建立在**事实与原方向**上；禁止无理由替换成完全不同的解释。
- 禁止：把疑问写成结论；把可能性写成绝对事实；因查到新东西随意改变全文主题。

## D 进入正文的前提

- 与 User Core 方向一致；
- 有材料支撑（R）；
- 不把作者原有疑问强行封闭；
- 不把可能性写成绝对事实。
