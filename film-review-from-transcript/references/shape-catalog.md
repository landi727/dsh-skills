# Shape Catalog（结构自然形态目录）

用途：给 Step 3 提供"合法结构形态"的对照视野，防止只会套三段论。
铁律：**结构必须来自当前 Opinion Map 的观点关系**，不是从这里挑一个套上去。写 Shape 说明时注明"为什么这个顺序属于这份材料"。

常见自然形态：

1. **单线推进**：一个核心判断 + 逐渐展开的依据（观点聚焦的材料）。
2. **过程式**：按观影过程/感受变化的时间顺序写（"先觉得 X 后觉得 Y"的材料）。
3. **对比式**：两部片/两个角色/两种拍法的对照（材料本身含对比时）。
4. **疑问式**：以用户未解决的问题为主线，判断挂在疑问上（犹豫多的材料）。
5. **清单式**：若干独立观点并列、各有轻重（聊天碎片；禁止每点同样篇幅）。
6. **混合式**：以上组合。

禁止：总-分-总三段论；为结构整齐牺牲材料本来的层次与轻重。
