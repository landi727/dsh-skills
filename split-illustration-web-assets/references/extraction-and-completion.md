# 提取、补齐与导出

目录：来源与精度 → 拆层表 → 工具边界 → 原像素与透明蒙版 → 遮挡补齐 → 背景扩画 → 分辨率与范围 → 静态检查 → 失败处理。

本参考用于把已确认的插图制作成静态网站素材。以原画保留、结构完整、可重组为目标，适用于任意网站场景与主体。

## 1. 先确认来源与可达到的精度

按以下顺序选择来源：

1. 已有原生分层文件、矢量对象或独立素材。
2. 同项目已确认、能与母版匹配的透明素材。
3. 扁平母版中的可见像素与可用蒙版。
4. 仅对缺失区域生成补绘。

读取原生文件时保留组名、图层层序、透明度、混合模式和画布尺寸。
不能正确导出的混合模式先记录，再对照母版决定是否合并相关静态图层。
复用独立素材前核对版本、尺度、颜色和姿态；名称相同不代表内容相同。
扁平图片缺少原始遮挡信息，无法承诺恢复其真实原生图层。
没有可分离边缘的部分可能只能近似提取；在验收中写明偏差和影响。

## 2. 制作拆层表

每一层先写清名称、来源、包含对象、排除对象、遮挡对象与补齐要求。
用户已指定的分组优先使用；层内存在明显前后遮挡时说明能否完整提取。
避免把同一可见对象重复放入两个层，导致重组时轮廓加粗或颜色加深。
不因颜色接近就把不同物件合并，也不因颜色不同就把一个完整物件切碎。
静态装配需要整件物体时，补齐完整轮廓；范围由用户的素材要求确定。
用户要求“所有遮挡部分补全”时，不能只补当前可见的一小角。
未获证据支持的隐藏形体、纹样和结构均标记为 `inferred`。

## 3. 工具与授权边界

先读取实际可用图像工具的约束，再决定操作路线。
生成补绘、扩画、透明切图等生成式编辑使用现有 `imagegen` 能力。
工具要求先查看本地图片时，必须先查看，再将其作为编辑目标传入。
不擅自切换外部 API、安装分层模型或索取密钥。
用户未选择 CLI/API 路线时，不把质量或尺寸问题作为切换理由。

确定性代码路线仅用于已明确授权的蒙版提取、原像素合成、裁切和缩放。
代码只处理已有像素和指定蒙版，不模拟生成补绘或臆造缺失结构。
运行环境禁止 Python 图像编辑时，遵守该限制；本参考不能覆盖上层约束。
用户明确授权的代码路线与当前工具能力不相容时，报告限制并采用允许的方法。
无法获得原像素级保留能力时，将结果记为近似素材，不声称完全不变。

## 4. 原像素与透明蒙版

保留只读母版；所有提取操作使用新文件和稳定的素材编号。
区分颜色信息与透明度信息；检查文件中确实存在 alpha 通道。
棋盘格、白底或黑底被画进 RGB 的图片不能作为透明素材交付。
优先使用原生 alpha 或经检查的蒙版；蒙版需与母版坐标一致。
可见区的 RGB 应来自原图；蒙版只决定保留程度，不重新绘制该区。
对半透明边缘保留合理的渐变 alpha，避免切出硬锯齿。

单纯按 RGB 明暗阈值提取线稿容易误删黑毛、暗衣服、阴影和深色填色。
没有可靠原生线色图层时，保持整体素材，不默认执行线色分离。
草叶之间的空隙、绳圈内部、枝杈孔洞和细线之间的空白必须保留。
不能只提取外轮廓后填满内部，导致这些孔洞消失。
透明边缘若带有原背景残色，先定位污染范围，不对整张素材统一去色。
颜色本来属于主体时保留；无法确定时对照母版放大检查。

## 5. 遮挡区域补齐

为每层保存三类区域记录：原图可见区、需要补齐区、保持透明区。
生成前明确补齐区域的轮廓、相邻线条、色块、纹理和结构依据。
同一物件的延续可依据可见部分推断；不可见的新结构仍标记 `inferred`。
补齐内容延续母版的绘画方法，禁止额外添加装饰、道具或光影。
被遮挡的背景应延续实际背景，不把前景物残影复制到背景层。
完整素材补齐需要检查所有遮挡区和被画框裁掉的区，不只检查外接矩形。

编辑提示词明确限定可修改区域，并列出需要保留的可见区域。
工具无法用硬蒙版锁定输出时，不把文字约束当作像素不变保证。
若已获允许的合成能力，将生成结果严格限制在补齐蒙版内，原可见区继续使用原图。
若当前约束不允许这种合成，仅通过图像工具完成并复核；保留失败则报告失败。
补齐区与可见区交界需要逐段查看，防止线条断裂、双边和纹理接缝。
邻接线条可以向补齐区延续；不得为了接顺而大范围重画可见主体。
角色补齐同样遵守这些规则，不能以重新生成整个人物替代原图提取。

## 6. 背景向外补画

先取得母版显示区域、目标屏幕比例、静态缩放或裁切方式，以及指定扩展边距。
母版边界与扩展边界分别记录；扩展后的坐标允许位于母版范围之外。
覆盖需求缺失时，完成已确定的范围，并把额外覆盖标为未验证。
不凭经验声称某个固定百分比可适配所有网站。

扩画是在原画四周新增有效图像内容；增加透明空白不会增加背景覆盖。
新增内容需延续颜色、纹理、地面或建筑的连续关系。
四个角必须检查，不能只补四条边后留下空角。
主体之外的背景若本应连续，补齐被角色、幕布等遮挡后的背景区域。
扩展区不能用镜像、拉伸或重复贴片冒充自然补画，除非用户指定该处理。
扩画不改变母版范围内已确认的构图；发生变化时记录并判为未通过保留检查。
要求比母版更宽的视野时，保留原坐标，新增内容向外增长。

## 7. 三倍分辨率与输出范围

三倍分辨率指最终像素宽高分别为基准尺寸的三倍。
扩画指画面覆盖范围增长；两者分别记录，不能互相替代。
例如母版为 1000 × 800，四边各扩 100 个基准单位后，范围为 1200 × 1000。
该扩展画面的三倍导出尺寸为 3600 × 3000，装配仍使用基准单位。

优先从矢量或高分辨率原生层导出需要的尺寸。
只能放大扁平图时，注明插值或其他实际方法，不宣称新增了原始细节。
生成补绘的原始输出尺寸不足时，同样注明后续放大方式。
不通过过度锐化掩盖不足，避免线条发白、描边变粗和纹理变硬。
保留无损母版；网页版本按实际显示需求导出，透明度与颜色须再次检查。
透明素材优先保存 RGBA PNG；使用其他格式前确认其透明度与实际解码结果。

## 8. 提取后的检查

在透明棋盘、黑底、白底和接近网页底色的背景上查看每层。
检查细线、尖角、草叶、孔洞、半透明边缘和隐藏补齐的交界。
将层按原坐标重组，与母版并排及叠加对照。
可见像素保留结果与生成补齐结果分别评价，不用补绘好看掩盖原画变化。
缩小到目标显示尺寸后再查看，确认轮廓、颜色和纹理仍可辨认。
数值差异检查用于定位；结构、残色、假细节等问题仍需人工视觉判断。
未实际查看的素材或区域不得写为已通过。

## 9. 最小记录与失败处理

记录每层的来源版本、提取方法、蒙版路径、补齐区、扩展区和放大方法。
输出状态采用 `passed`、`failed`、`unverified`，推断区域另标 `inferred`。
失败时保留已通过素材，只修对应区域或对应层，不整组重新生成。
不能可靠拆分的对象保留可还原构图的合并层，并明确未完成的细拆要求。
完成度以实际文件、静态重组和检查结果为依据；不把提示词中的约束当作验证。
