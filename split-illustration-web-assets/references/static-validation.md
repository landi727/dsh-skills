# 静态验收

## 自动检查

执行 `scripts/inspect_assets.py --manifest <scene.json> --out-dir <checks>`。依赖 Python 3 与 Pillow，不需要图像生成模型或联网。

脚本核对必填数据、唯一 ID、源文件、尺寸倍数、实际 alpha、逐层有效尺寸与指定背景覆盖；按 z 重组实际素材，并输出：

脚本当前支持 PNG/WebP 导出层。用户指定其他格式时优先遵循该要求，另保留 PNG 母版用于检查；目标格式的透明度与解码效果单独验证，不把脚本暂不支持某格式认定为该格式本身不合格。

- `composite.png`：原坐标静态重组。
- `reference-diff.png`：原图区域的 RGBA 像素差异可视图；用来定位变化，不等同于美术评分。
- `edge-contact-sheet.png`：每层在黑、白底上的静态缩略图。
- `report.json`：尺寸、透明度、覆盖、差异指标、错误与需人工核对项。

有 resolution 时按实际 alpha 有效边界核对目标像素；原生尺寸不足提示需要放大和画质复核，导出有效尺寸不足则硬检查失败。缺少尺寸要求时标为未验证，不能把自动退出码 0 写成素材尺寸适用性通过。

退出码 0 表示自动硬检查通过，仍需人工视觉验收；退出码 1 表示存在硬检查失败。源图重组完全一致可标为精确；有差异只能标为需视觉复核，不能由单一平均误差阈值自动认定原画保真。

非背景素材默认要求真实 alpha 通道及至少一个 alpha 小于 255 的像素；合理的不透明矩形使用 `opaque_allowed:true`。指定 `opaque-rect` 的区域逐像素检查 alpha 至少为 254。该检查不能发现被画进不透明背景的假细节，仍要视觉核对。

补绘蒙版的自动检查仅限存在、尺寸和可读取性。有效补绘范围与可见原画保留需要另查来源证据。对边缘锯齿、白边、阴影、黑毛及画风统一性，脚本只提供检查图，不能自动给出通过结论。

## 人工静态检查

| 检查项 | 要求与证据 |
|---|---|
| 分组完整 | 用户指定内容均存在；不缺道具或藏入错误分组 |
| 设计保留 | 构图、主体尺度、轮廓、颜色、纹理与确认原图一致；补绘没有改变可见设计 |
| 遮挡关系 | 原坐标重组层序正确；后方素材不含前方遮挡物；独立查看可确认补全区域 |
| 透明边缘 | 黑白底均无明显残底、颜色污染、白边、孔洞、细线断裂；有意孔洞保持透明 |
| 补齐合理 | 缺失结构延续合理，与原图接缝自然；推断区域已标注 |
| 背景覆盖 | 每个指定矩形都被实际有效内容覆盖；不能仅看文件宽高或 alpha 包围框 |
| 静态裁切 | 在全部声明视图下构图符合要求，主体不被意外截断；有意裁切单独记录 |
| 高清与导出 | 按每层有效区域检查目标像素；原生细节、重采样、生成新增细节区分清楚；在目标显示下查看模糊、锯齿、细线、纹理与放大变形。尺寸达标和画质通过分别判定 |

在实际显示尺寸和原生像素尺寸分别查看。接触图缩略图用于定位问题，细小毛发、透明线条和接缝须打开原尺寸文件检查。不要只看整张缩小图。

## 静态预览

复制 `assets/preview.html` 到素材包，通过系统文件选择一次载入 `scene.json` 和所需图像；浏览器支持目录选择时可以选整个包。模板在本地内存中读取文件，不上传。

使用预览选择图层、黑/白/棋盘底、原图/重组/差异和 `target_views`。模板按原图逻辑坐标直接画图层，扩画中的负偏移保持正确。目标视图只显示清单里声明的静态查看范围，不能代表完整响应式网站已通过验收。

不要把模板预览替代最终网站的截图检查。技能交付结论只覆盖素材与已声明的静态视图，不覆盖网站交互、性能、动效或后续变更。

## 报告与修复

为每项填写 `passed/failed/unverified`，用具体证据支持。自动检查和人工视觉判断分别列示；没有目标视图时将适配标为未验证，没有运行检查时明确说明。

失败时只改对应素材及其依赖的清单；重新检查该素材、重组画面和受到影响的覆盖/裁切，不重做全部已通过项。在当前任务授权内继续针对性修复，按 SKILL.md“交付与失败处理”判断生成边界；仅在用户明确限制次数或需要扩展授权时停止相关生成，不默认一次生成后结束。保留前一个可回溯版本，勿用未经检查的新文件覆盖它。待修报告用于记录状态，不替代完成修复与验收。
