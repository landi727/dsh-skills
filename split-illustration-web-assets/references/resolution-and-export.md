# 小尺寸输入与逐层尺寸验收

## 1. 确定目标尺寸

在拆分前记录每层有效绘制区域在各目标网页视图中的显示宽高，取两轴各自的最大值，单位为 CSS 像素。有效绘制区域不包括透明空边；从整层显示框计算时，按内容包围框占整层文件的比例换算。最大宽高可能来自不同视图，需都满足。

`target_views.width_px/height_px` 表示静态预览的输出像素，不能直接当作网页 CSS 显示尺寸。根据真实容器 CSS 尺寸计算 `resolution`；无法取得真实布局时，只验证清单声明的尺寸要求，并将实际网站适用性标为未验证。脚本不自动证明显示尺寸声明与网站布局一致。

明确约定备图倍率 `pixel_ratio`，它表示目标素材像素与 CSS 显示像素之比，不是图像 DPI，也不必等于设备的全部硬件像素比例。用户指定三倍时使用 3；已有网站可采用已确认的渲染密度。没有确定倍率时标为未验证，不擅自套固定三倍规则。

计算：`目标有效宽 = ceil(最大有效显示宽 × pixel_ratio)`；高度同理。例如有效主体显示 400×500 CSS px，按三倍备图需要至少 1200×1500 个有效像素。即使源场景宽 2000px，主体原生宽仅 200px，也仍需单独处理该主体的尺寸。

内容覆盖范围和像素密度分别计算。背景向外补画满足覆盖需求后，还需核对其显示尺寸对应的目标像素；增加透明画布不能增加有效绘制像素。等比放大保持形体比例，不能拉伸宽高来分别凑尺寸。

## 2. 记录原素材与处理路线

记录源素材在任何放大之前的有效绘制宽高；不能把已经插值到 1200px 的文件重新声明为原生 1200px。扁平插图按具体对象原生可见区域测量；存在隐藏补绘时，记录可见原生部分与新补绘部分的来源，不把补绘说成原图细节。

优先取得版本匹配的高分辨率原图、原生层或矢量对象。原生像素充足时直接导出，矢量按目标尺寸渲染；无法取得时再按实际工具、授权与图像特点选择保真放大或重采样。不要为了满足像素数擅自重画主体、改变线条或增加纹理。工具能力不足时报告限制，不用“高清”提示词代替真实文件检查。

保留原生母版与处理后版本。明确实际方法：`native`、`vector-export`、`resampled`、`super-resolution`、`generated-completion` 或 `mixed`。采用超分辨率仍需核对新细节是否改变确认设计；不能承诺恢复原图未记录的信息。采用确定性代码编辑时遵守当前图像工具限制与用户授权。

## 3. 清单字段

对有网页尺寸要求的每层填写以下 `resolution` 对象：

```json
{
  "max_display_width_px": 400,
  "max_display_height_px": 500,
  "pixel_ratio": 3,
  "source_effective_width_px": 200,
  "source_effective_height_px": 250,
  "processing_method": "resampled",
  "visual_quality_status": "unverified"
}
```

前三个字段必须为正有限数，原生有效尺寸若已知则成对填写为正整数；未知时省略该对字段并标为未验证。原生尺寸必须来自可核查的源图、原生层或原始提取记录。`visual_quality_status` 用 `passed/failed/unverified`，仅记录已进行的人工检查；脚本不能证明该声明。

`max_display_width_px/height_px` 指有效内容的最大显示范围；`width/height` 仍指整个图层文件的一倍逻辑尺寸，两组字段不能混用。`export_scale` 是从一倍母版坐标到文件像素的倍率；`pixel_ratio` 是从网页有效显示像素到目标备图像素的倍率，两者可能不同。

示例：主体一倍文件宽 200、导出倍率 6，则文件宽 1200px；网页有效显示宽 400、备图倍率 3，目标宽也是 1200px。正确装配仍沿用一倍坐标，不把网页显示 400px 或文件宽 1200px写成母版逻辑宽 200px的替代值。

## 4. 尺寸与画质分开验收

运行检查脚本，分别读取：

- `size_status`：实际导出有效像素是否在两轴均满足目标；不足为失败，缺目标为未验证。
- `source_sufficiency`：声明的放大前有效像素是否够用；不足时记录所需最大放大倍率，只能表明需要处理，不等于处理后的画质必然失败。
- `visual_quality_status`：脚本固定为 `not-auto-verified`，另保存人工声明；尺寸满足仍需实际查看。

导出有效范围以 alpha 大于 0 的包围框测量，排除完全透明空边。包围框只能证明有效像素范围，不能证明细节真实、内部结构清楚或边缘没有污染；零星残色可能扩大包围框，需视觉核对。全透明素材的有效尺寸为零，不能通过。

在目标显示尺寸与原生像素尺寸分别查看：主体轮廓、细线、孔洞、锯齿、模糊、纹理和补绘接缝；对放大前后版本核对是否出现假细节、色偏、粗线或形体变化。使用无损母版检查，网页压缩版再次核对颜色与透明边缘。

出现问题时仅调整对应素材的来源或处理路线。没有通过画质检查时标为失败或未验证，不能以文件宽高满足要求结束验收。
