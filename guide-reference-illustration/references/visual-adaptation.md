# 视觉适配与核对

只使用影响当前目标或已经出现偏差的条目。不要把此表扩写成每次必做的全维度报告；无明显歧义时允许直接以参考图生成。

| 维度 | 对照原图观察什么 | 如何形成有用的补充 |
|---|---|---|
| 形体与身份 | 形体如何概括，哪些轮廓、花纹与体型关系决定辨识度 | 说明新对象怎样被同样概括，保留必要特征；不机械复制原对象形状 |
| 线条与边缘 | 是否有轮廓线、线重变化、边缘松紧，以及前后物体的处理差异 | 指明角色与背景应共同采用的方式；不默认加黑边或统一描边 |
| 色彩与塑造 | 大色块的面积关系、明度与冷暖关系，平涂、阴影、渐变、纹理各自的作用 | 指明哪些关系要保持、哪些区域可变；具体颜色以本任务为准，不默认套命名色系 |
| 构图与空间 | 视角、主体尺度、前后遮挡、聚散与空处如何组织 | 根据新内容重新安排位置和关系；视觉重点不等于把角色放得最大，留白不等于删掉所有内容 |
| 动作与场景 | 姿态重心、手脚与道具接触、角色和环境的叙事关系 | 给出可成立的动作或位置调整；不要仅把角色贴进背景 |

把偏差描述落到位置和现象：例如“猫和背景是纯色色块，但新加入的狗有大量毛发细线；应把狗的毛发概括程度统一到本图”，优于“整体再高级、再统一一些”。这是表达方式示例，不是所有任务的默认画法。

区分观察到的事实与建议的修正原因。整体颜色偏离可能来自新增阴影、背景面积或灯光处理；未核实前不要直接归因于某个模型缺陷。

对需要精确交付的属性分别核实：尺寸读取文件数据，透明度检查真实通道与内容，文字逐字查看。仅凭提示词或缩略图不能声称这些属性已满足；只能看到预览时说明检查范围。
