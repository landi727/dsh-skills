# 目的驱动的文档生成

交付符合用途、信息可靠、关系清楚且可直接阅读的文稿。按“目的 → 标准 → 信息 → 关系 → 结构 → 正文 → 验收”工作；简单材料可合并步骤，不省略关键检查。默认内部完成标准、账本和验收，不把这些过程变成用户的填写任务或附加交付物。

## 1. 确定用途与工作边界

从当前要求和可用材料确定：帮助谁完成什么、读者已知什么、阅读后的动作、达到何种深度才可用。以当前明确指令优先，保留仍适用的前文约束。不要把“正式”解释为更长、更多章节或达到开发级细节。

区分本次操作，混合任务按内容分别处理：
- 整理既有内容：保留原意、重要维度和有效修订，允许重组、归纳及范围内的必要推导。
- 形成新方案：允许在授权目标和范围内提出机制、建议及细节；标明方案性质，不冒充已采用决定或已验证事实。

目的可合理推知时直接完成。仅当歧义会实质改变结论或整体组织且无法由材料解决时，提出一个必要问题；局部缺口留在相应位置并继续可完成部分。不要逐项索要用户确认。

## 2. 把目的转成可检查的标准

保留通用底线：原意不失真、重要信息不遗漏、无依据内容不冒充事实、关系不伪造、重复不掩盖差异。再按用途选取少量专项检查条件，不做权重打分，不套完整模板。

把“清晰、完整、可执行”等形容词转成具体条件，并对应本次要求。例如：产品设计中的重要问题有对应机制，机制在模块或流程中有落点；执行方案的关键动作有对象、必要条件和结果；结论整理保留有效修订及未解决分歧。仅在任务要求该深度时使用这些条件。

正文生成前确定标准；验收时保持同一标准，不能为了通过而降低要求。若材料揭示目的或范围需调整，说明影响，避免悄悄换题。

## 3. 整理信息与依据

内部只为重要、易混淆或存在争议的内容保留简要记录及可追溯来源位置。不要对每句话建立庞大账本。分开判断三个维度，不混成一列等级：

| 维度 | 判断内容 |
| --- | --- |
| 内容性质 | 事实陈述、推断、建议或方案、采用决定 |
| 依据情况 | 来源直接记载且足以支持该表述、可追溯依据支持的推导、依据不足、来源冲突 |
| 采用状态 | 当前采用、仍在讨论、已被替代或撤回；不适用时不标 |

- 原材料明确记载只证明“材料这样说”；用户确认方案不证明其效果成立。证据强度与采用状态分别处理。
- 根据后续讨论的实际承接和修改判断当前工作版本，不要求每项都有“确认”字样。沉默不等于确认，继续讨论也不代表接受整份方案。
- 有明确替代关系时采用后续修订；仅时间较新不足以覆盖旧结论。冲突无法解决时保留差异及影响。
- 可追溯的推导可以进入正文，但保持相应语气和条件；不能把多次重复或多个转述当成独立证据。
- 影响判断的当前外部事实应查证；无法核实则说明有限依据。普通原文整理不默认扩展为全面调研。
- 对不确定内容按影响处理：影响主结论的说明前提和待验证点；局部不确定性就近限定。不要因未确认就删除有用内容，也不要让标签充斥全文。

## 4. 控制补充并建立关系

先识别内容的实际角色及包含、先后、依赖、因果、修订关系，再拟目录。

允许补足衔接、明确省略的指代、归纳已有规律、展开既定机制所需的说明。发生实质推导时保留依据与推断性质，避免把整理压缩成摘抄。

在整理任务中，新增目标、功能、受众、资源承诺或改变方向的内容，只能在确有必要时列为待讨论建议；在方案生成任务中，按授权范围提出。没有依据的数字、效果、承诺和决定不得自行填入。

不要把相关当因果、表现当原因，或为了串联目录虚构推导。缺少关键环节时说明缺口，允许结构不对称。章节按读者完成任务所需的理解顺序组织；可先给结论，再按前提、依据和方案展开，不让读者反复寻找尚未解释的概念。

## 5. 生成正文：层级、去重与并列项

- 每章承担一个明确职责，标题准确概括下文；不套预设的产品、分析或创意目录来补齐空内容。
- 同层分类采用同一维度和粒度；真实的包含关系改为上下级，先后或依赖关系改为流程。分类下的条目避免交叉归属；不同维度的合理比较可用表格。
- 每个要点有一个主要展开位置。后文只补充新依据、条件或应用，必要时简短回指；摘要可概括结论，不能再复制完整论证。
- 并列选项回答同一个决策问题，处于相同层级，并有可说明的实质差异。共有基础集中说明；可组合的说明组合关系。不要把总方案、子功能和实施方式包装成三个备选方向，也不要强求所有方案完全互斥。
- 去掉标题和修饰词，检查每项新增了什么。没有独立增量就合并或删除；有不同条件或不同后果则保留差异。不得为凑数量拆分同义项。
- 使用直接、具体的表达，先呈现影响理解和行动的要点，再给必要解释。避免无意义前缀、反复总结和“不是……而是……”式强调；不把复杂关系压成难懂的关键词。

## 6. 按原标准验收并交付

回看输入和正文，完成三种检查，不用笼统的“均符合”或无实测支撑的分数代替：
1. 输入到正文：重要要求、有效内容、限制和修订是否都有恰当落点？是否因未明确确认而误删？
2. 正文到依据：重要事实、结论及补充是否有来源或明确性质？是否越过本次范围？专项标准是否满足？
3. 正文内部：去掉标题后是否仍有同义反复、选项包含、层级错置、前后矛盾或依赖倒置？结论与实际机制是否衔接？

先修复影响目的、真实性和结构的问题，再修表达。修改后检查关联位置；若整体结构错误，可重组必要范围，避免仅做局部修补。修复后做一次针对性复查，剩余无法解决的材料缺口如实交代，停止无新增依据的反复润色。

交付用户要求的文稿及确实影响使用的未决项。默认不附账本、标准表、修订历史或验收报告；用户要求时再提供。不承诺自检能保证绝对准确。用户指定文件格式时，按相应可用文档工具完成排版与交付，本技能负责内容组织。
