# 插图动效专项检查

## 检查方法

采用“原速整体观察 → 关键帧／极值定位 → 对应技术或几何检查”。保留同一素材、版本和视口的对照，记录缺陷出现的时间与触发路径。

| 检查对象 | 要检查的可见结果 | 可自动检查的范围 | 需要视觉判断的范围 |
|---|---|---|---|
| 关节与身体 | 袖口、腋下连接，肘部厚度，轮廓连续，褶皱随形与遮挡交换 | 坐标、面积、交叠或透明缝隙提供线索 | 体积可信、动作意图、褶皱被不合理遮盖 |
| 固定部位 | 裙摆摆动时脚和小腿稳定，固定背景不跟随前景 | 锚点或区域差值，排除相机与抗锯齿误差 | 是否牵连或为了固定造成僵硬 |
| 角色身份 | 毛色分区、耳内色、服装、比例和识别特征稳定 | 原色、尺寸、锚点偏差提示漂移 | 转向、受光的合理变化与身份一致 |
| 动作连续 | 预备、主体、跟随和收势联系，转身包含真实姿态变化 | 相邻帧差、轨迹、播放时序 | 重心、头耳衣物跟随和节奏 |
| 遮挡 | 前后层交换自然，补齐处完整，手臂不任意盖住衣服结构 | 层序、透明区域、交集 | 是否符合姿态与空间关系 |
| 镜头与屏幕 | 构图、脚部、植物完整，背景全程覆盖 | 逐帧坐标与有效 alpha 覆盖 | 镜头和裁切是否符合表现目的 |
| 清晰度 | 线条和纹理保留，效果开启后不异常变糊 | 源、导出、渲染尺寸与像素比，局部对照 | 原图质感与新增模糊、锐化失真 |
| 形变与光晕 | 仅影响声明对象，线色关系保留，固定对象不受影响 | 作用层、遮罩、区域差异和配置 | 形变自然，光晕明显且不过强 |
| 极值、循环、中断 | 最大摆动、遮挡切换、末首帧、离开和重触发均正常 | 状态转换、帧号、时序 | 突跳、截断或恢复突兀 |
| 多视口 | 横竖屏布局、脚部、覆盖和交互范围符合要求 | 各视口与 DPR 截图、坐标、覆盖 | 构图、尺寸和视觉层级 |
| 目标设备 | 原速持续稳定，触发响应及时 | 帧间隔、掉帧、负载 | 可见卡顿，统计不等于观看体验 |

## 清晰度故障分层

1. **源图**：确认尺寸和局部清晰度，检查已有模糊或裁切；放大不恢复细节。
2. **导出**：对照源图检查缩放、压缩、透明边缘、补绘、帧规范化；记录有效内容面积，避免画布大但内容小。
3. **渲染**：检查 CSS 尺寸、DPR、Canvas drawing buffer、WebGL render target、纹理采样与 mipmap、后处理降采样、颜色空间与 alpha 混合。

固定时间点、视口和缩放比较效果关闭／开启，定位环节后再改参数。

## 背景覆盖脚本的坐标合同

脚本需要 Python 3 与 Pillow。先检查当前可用的 Python 环境；依赖缺失时明确报告未运行，不将缺失检测当作覆盖通过。

`coverage.example.json` 是结构示例，不含可用素材，也不代表真实动作已验证。

- `width`、`height`、`required_rect: [x,y,w,h]` 使用**视口逻辑坐标**，矩形须位于视口内且宽高为正。
- 每层必须有实际、静态 **RGBA 文件**、`logical_size: [w,h]` 与 `base_position: [x,y]`，后两项使用**基准场景逻辑坐标**。透明画布保留在源尺寸中，不能用内容 bbox 替代。
- 六参数矩阵 `[a,b,c,d,e,f]` 定义 `x'=a*x+c*y+e`、`y'=b*x+d*y+f`。`layer_transforms` 作用于素材基准放置后的场景坐标。每个视口、每帧、每层都显式填写。
- `scene_to_viewport` 映射该帧场景到视口；包含相机平移、缩放与屏幕适配。
- 源像素到基准场景矩阵 `B`、层变换 `L`、场景到视口 `S`，总变换为 `S × L × B`。绕点旋转先在业务侧计算含枢轴的矩阵。
- `groups` 声明共同覆盖矩形的背景层组，`layer_ids` 使用上述层 ID；合成组内实际 alpha，不同组独立验收。存在遮罩、透明度、混合或裁切时，导出能代表其**有效 alpha**的素材或捕获实际渲染；普通静态文件无法替代这些操作。
- `alpha_threshold` 取 1–255，默认 250；代表可接受不透明程度，不证明颜色正确。`sample_density` 为每逻辑单位的栅格数量，默认 1；DPR 可作为候选密度，但结果仅在声明精度下成立。
- 使用双线性 alpha 采样与 source-over 合成，不模拟真实纹理滤镜、网格、shader、遮罩、透视或后处理。低于网格精度的孔洞可能漏检，边缘可能受采样差异影响。

## 证据边界与素材交接

每帧报告覆盖比例、未覆盖像素数、定位范围和是否触及矩形边缘；每组报告最差采样帧。诊断 PNG 保存要求矩形内的合成 alpha，白色更不透明、黑色未覆盖，不修改原素材。

采样关键姿态、运动和相机极值、遮挡交换、各交互状态。等距抽样不足以证明连续时间最差状态；非线性形变和 shader 运动需实际渲染逐帧检查。未来帧、未采样时段与未测设备保留未验证。

素材要求注明缺失类型：边缘延展、内部透明孔洞、遮挡补齐、坐标错误、分辨率不足。没有定位证据时先安排实验。将覆盖矩形、运动范围、有效素材坐标与目标像素需求交给静态拆图流程，不统一套用固定边距或三倍尺寸。
