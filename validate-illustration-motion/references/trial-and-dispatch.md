# 小样路线、派发与失败定位

## 选择技术候选

| 候选 | 优先试验的情况 | 小样必须暴露的风险 |
|---|---|---|
| 图层平移、旋转、缩放 | 可保持刚性、幅度较小 | 连接缝、枢轴、固定对象被带动 |
| 骨骼／网格／shader 形变 | 柔性轮廓或局部变形 | 体积、拉伸、模糊、作用域 |
| 关键姿态重绘与中间帧 | 转向带来轮廓与遮挡变化 | 身份漂移、锚点跳动、节奏、补齐 |
| 整条生成后切帧 | 工具能稳定生成所需序列 | 帧间不一致、尺寸漂移、无效姿态 |
| 关键帧插帧 | 正确关键姿态和稳定过渡结构 | 肢体融合、五官漂移、遮挡误判 |
| 混合路线 | 单一路线只能覆盖部分目标 | 切换接缝、节奏与画质不一致 |

按参考准确度、身份与风格、运动质量、设备表现、可控制与可局部修复程度、制作成本比较候选。缺少数据时标注成本估计，不给虚构评分。用同一动作区间试验；达到条件后选较简单且便于维护的方案。

转身改变朝向：保留识别、比例、画幅与锚点；头、耳、身体、衣物和道具按动作联系变化。姿态结构明显变化时，替换五官、交叉淡化或拉扯原画通常不足，用小样比较其他路线。

检查 Agent 读取有效基准和最终成果，保留自身判断。独立素材诊断可并行，共同场景配置与层级修改顺序推进。比较路线时给相同原始输入与条件，不共享预设结论。

## 失败定位与受控修改

1. **复现**：固定时间、触发、素材版本、视口、DPR 和设备，保存最短证据。
2. **定位环节**：检查源素材、导出、坐标层序、驱动、相机适配、渲染效果，比较近期变更。
3. **验证假设**：写可被反驳的原因，用关闭后处理、固定枢轴等最小实验验证；每次只改一项。
4. **最小修复**：修改已定位环节，记录影响对象与文件，保留其他确认选择。
5. **复验**：重复原条件，检查身份、固定对象、同素材使用处和相关视口。修好某帧后原速看完整区间。

连续实验无改善时重查素材条件、参考理解或路线，避免盲目重复。坐标、alpha 和自动差异提供线索，自然感与风格须视觉判断。

## 借鉴来源与限制

- [Superpowers systematic-debugging](https://github.com/obra/superpowers/blob/main/skills/systematic-debugging/SKILL.md)：先复现、查根因、做最小实验；通用调试不能代替动作视觉评估。
- [Superpowers verification-before-completion](https://github.com/obra/superpowers/blob/main/skills/verification-before-completion/SKILL.md)：完成声明需当前证据；命令成功只证明检查覆盖的事项。
- [Impeccable](https://github.com/pbakaus/impeccable)：吸取 animate、audit、critique 分别处理动作意图、技术检查和视觉质量的划分；界面动效标准不能直接充当角色表演标准。
- [2dimg2motion keypose-redraw](https://github.com/WU-HAOTIAN34/2dimg2motion/blob/main/references/keypose-redraw.md)：先检查关键姿态作为候选做法；效果与工具兼容性仍须按本次素材和动作验证。
