# 从插图延展图形语言

## 证据的边界

同时看整体和关键局部，标明取自哪张图哪个部位。实测、估算、建议分别记录。纯插图只支持相应的绘画特征，正文网格和字体需要另行设计；无法读取的图片不算看过。

| 观察层面 | 提取的关系 | 延展时决定什么 |
| --- | --- | --- |
| 形体 | 轮廓软硬、转折、圆弧、比例、正负形 | 框角、端点、遮罩、分隔和标题轮廓 |
| 线条 | 粗细关系、连续/断续、粗糙度、线色与填色关系 | 结构线、辅助线、图标与轮廓级差 |
| 色彩 | 背景、主体、强调、文字的明度/饱和度关系与面积 | 色彩角色及允许组合，可补充阅读底色 |
| 材质 | 纸/墨/颗粒/平涂的尺度、密度与分布 | 共享什么质感，正文区减弱什么 |
| 空间 | 平面/体积、遮挡、景深、接触、投影 | 图文叠压、层次、阴影和浮起程度 |
| 组织 | 密度簇、留白形状、重心、大小关系、方向 | 重音、节奏、装饰出现的位置 |

选真正决定该项目识别度的少数规则；不把每项细节搬进每个组件，不把配色相似等同于风格一致。

## 关键机制与比较方法

为关键机制分配稳定编号，注明来源部位、适用物类、在目标中必须保持的做法及失败迹象。优先固定识别机制，允许主题与构图变化。表述须能指导画法，例如“外轮廓与叶脉同为轻细墨线，曲线保留小幅不齐；用单层色片和遮挡塑形，内部线以结构识别为止”。仅当参考支持时采用这些规则，不能把例子变成通用画风。

分别检查外轮廓和内部线：颜色、相对粗细、连续性、转折、抖动和线的用途。分别检查形体概括与空间：轮廓如何被压扁/拉长，细节如何合并，体积由哪些手段表达，透视结构允许到什么程度。保留全局规则和局部例外，避免“手绘线”统括所有对象。

比较时选能对应同类机制的原图与目标局部，以相近显示尺度并排查看；优先比较线条、形体、填色/材质、空间和疏密。必要时补充灰度或去色视图，但不能用它替代颜色检查。全图用于检查构成与色彩分布，局部用于核查绘法。记录能定位的相似与偏离，不能仅靠整图印象判通过。

人物、建筑或其他原参考未示范的类别先做目标映射：识别特征如何被该形体规则概括，哪些透视线、衣褶、材质和小细节需要限制。把它当作待验证推导，生成结果经局部对照通过后才纳入已验证规则。

## 推导可制作的部件

为必要元素填写下表，同一规则引用即可。

| 字段 | 应回答的问题 |
| --- | --- |
| 信息用途 | 帮助读者识别、阅读、比较或行动什么？ |
| 视觉依据 | 取用哪条形线色材质空间规则？是观察还是建议？ |
| 转译方法 | 如何抽象轮廓/笔触/构成关系，使其适合这项功能？ |
| 固定与变化 | 哪些线宽、角部、字体角色固定，哪些长度/方向/位置可变？ |
| 组装条件 | 尺寸、内边距、内容区、层次、裁切、延展、邻接怎么处理？ |
| 失败表现 | 哪些做法会串风格、抢信息、拉伸、拥挤或不可读？ |

可涉及标题、正文承载区、图片底托、引文/数据、标记、分隔、底纹、收尾品牌区。只选有用途的元素；星星、贴纸、编号、阴影和外框均不必全部出现。

方法示例：假设参考具有“纸片式色块、轻微不齐的切边、较粗暗线”，可让标题侧边、图片底托与章节分隔共享切边节奏，正文使用平整阅读底面；无需把整段文字塞进巨大叶片。此例不是已确认画风或通用模板。

让每次转译改变图文的组织方式：标题字面与图形如何互相留白，正文阅读面如何被边缘或负形界定，照片如何裁切、靠齐或嵌入，转场如何承接方向与视觉重量。引用同一种花叶只能说明题材相通；亲缘关系要在这些做法中成立。照片可保留真实影像，重点设计它与文字、周围图形和整篇的关系。

## 主动设计

- 主参考和内容优先。需额外灵感时查少量一手案例，明确借鉴的是字图关系、图形生成方法或节奏。用户要求当期趋势时核查当期来源，旧案例只作方法例证。
- “年轻”“潮流”“游戏感”须落实到字形、图形比例、颜色关系、图像处理和结构行为；不自动等于霓虹、故障、渐变、贴纸或拥挤。
- 允许有依据的大字、强色、拼贴、厚阴影、圆角和渐变，检查是否符合本项目；不将某个作者的偏好升格为通用禁令。
- 设计关键识别处理并规定重复与收敛的位置。每节增加新效果会破坏统一；复制同一布局会损害节奏。
- 字体参与视觉延展：检查中文覆盖、笔画粗细、字面、标点、数字及实际可用性，再分配标题和正文角色。英文品牌字体的气质可借鉴，不能假定其支持中文。
- 低清参考无法支持精确数值时，给出待看样调整的建议值，不伪造测量。

## 五个判断

1. 忽略颜色后，形、线、材质和空间是否仍有联系？
2. 暂去非必要装饰后，层级和阅读是否成立？只恢复承担识别或节奏作用的装饰。
3. 换段落/图片后体系是否仍成立，同时允许构图随内容变化？
4. 缩到阅读宽度，边框、颗粒和细线是否压字或消失？
5. 各模块既能看出亲缘关系，也能分辨不同信息用途吗？

这些是工作方法，不是自动测定审美的算法。用具体可见问题描述结果，避免只说“缺少高级感”。
