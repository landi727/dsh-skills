# 与现有技能协作

本技能负责整篇平面设计决策、视觉延展和最终效果。按需选用下游技能，不每轮全部启动、不重复规格。先检查可用性并读取当前版本；不可用时按本技能最低规则继续，说明具体缺口。

| 需要 | 可配合技能 | 分工 |
| --- | --- | --- |
| 继承已认可长图的排版经验 | inherit-longform-design | 读取真实成功案例，把信息主次、构图选择和章节关系用于新内容；按新布局精细制作插图 |
| 深入分析插图或形成生图蓝图 | analyze-reference-style / analyze-image-for-generation | 按所需深度选一种，回收绘画规则供平面转译 |
| 生成既定插图和栅格素材 | execute-illustration-blueprint + 生图工具 | 输入原图、蓝图、用途、尺寸、安全区，回收素材及检查结果 |
| 从完整平面参考提取版式 | design-longform-layouts | 回收网格、层级、密度和模块关系；插图没有的排版由本技能提出 |
| 把确认视觉变成可替换 HTML/CSS 模板 | build-modular-longform-templates | 输入已确认/已授权样板和基准，回收源文件、素材、导出及增长检查 |
| 公众号发布或动态/交互设计 | audit-wechat-article-compatibility | 核查实际投放条件与最新平台限制；静态方向不扩大为全平台审计 |
| 指定归档画风或需检索风格库 | manage-illustration-style-library | 取回参考和规则，不改换已确认方向，遵守其归档范围 |

下游确认要求与当前明确授权冲突时以当前用户授权为准；实际必要而未覆盖的重大决定需说明并询问，不假称已确认。

向下游交付原参考、关键规则编号、整篇总览、真实内容与本轮范围；回收实际提示词/传图记录、素材及对应局部对照。返回的技术通过仅用于技术项，仍由本技能审查绘法、延展和完整构图。模板技能负责实现已成立的设计，不能用默认封面比例、模块角色或可编辑要求反向决定长图外观。

已有确认稿的局部改文只检查受影响区域、邻接与完整缩览，复用仍有效的风格及构图证据。用户明确确认的多底色、海报首屏、框体等选择保留；只有本轮变化破坏阅读或既定规则时才修正，避免将质量修复变成无授权的重设计。

网站运行/交互审查交 `design-review` 等技能，不把平面任务扩成网站、编辑器、CMS或后台；不加载无关 hover、加载态和后端要求。
