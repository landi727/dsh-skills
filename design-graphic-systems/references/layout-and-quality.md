# 长图排版与质量检查

## 内容与阅读顺序

锁定事实与正文，区分标题、说明、主体内容、证据/图像、补充信息和行动信息。明确每个视觉章节的首要信息；并列比较允许多个同等级主体，不为“唯一焦点”破坏比较关系。

篇幅来自信息需要。资料只有标题、时间、区域和照片要求时，可形成短而完整的长图，关键事实保留待补；不要用套话、重复活动信息或无用途的装饰扩成预设长度。受委托撰写的文案须具体服务活动，区分创作文案与未确认事实。

先在一个完整总览里安排图文和照片，再划分实现单位。共享底层规则、贯穿或呼应的方向、留白和重心形成整体；分组不自动需要独立底色、闭合框或硬分割。不同底色或多个场景可成立，需能说明它们的阅读用途和连接方式。首屏复用海报也可成立，需基于明确用途或确认稿，并解决与后文的构图关系。

建立共用对齐轴、文字区、字号角色和间距关系，再安排有理由的偏移、叠压、出血。段间距显示分组，章节间距显示转换，框体强度服从信息的重要性。

逐节分配密度与视觉重量，高密度信息之后适当缓冲，重要节点获得更明显的对比。同种信息同种规则，不同功能可换组织方式；不以固定“每几屏一次留白”代替看内容。

## 手机阅读尺寸

区分源像素、导出像素、实际显示宽度与设备像素倍率：

`显示字号 = 源字号 × 实际内容显示宽度 / 源画布宽度`

未定参数时，正文可从约 16 CSS px 显示目标起试，行高从 1.5–1.8 倍起试。这是本技能的制作起点，不是微信规定或所有字体的合格线。

源宽 1000 px、实际显示宽 343 px 时，达到 16 px 约需源字号 47 px；显示宽 375 px 时约需 43 px。375 px 是模拟屏宽之一，不保证文章图占满屏幕，要考虑实际内边距。高分辨率导出不自动增大显示字号。

按字体字面与内容宽度检查每行字数和行段距，避免多列长正文。标题可明显变化；持续阅读正文不在每节任意跳字号。标题按语义断行，检查中文行首闭标点、行尾开标点、英文词和数字单位。

先通过增高、调整组织和语义拆节解决长文。未经授权不删文、不挤压字形、不缩小正文维持预设高度；可建议精简，改文意须有授权。

## 可编辑与内容增长

- 背景可延展，顶底装饰独立，边框重复保持自然尺度；人物、花、徽章不随正文高度拉伸。
- 文本流式排布，装饰相对模块锚定，仅明确固定区域使用绝对坐标。
- 初建模板用实际短、中、长内容验证，并检查长标题、缺图、异比例图片；局部改文只测试受影响模块与邻接，不重跑无关项。
- 少图时重组比例/省去空模块，不留无意义大洞；多图建立主次，图注与图片相邻。
- 先查完整构图再切片，避免切过文字、重要五官、Logo、二维码；复杂底纹接缝连续。
- 文件大小、格式和 SVG/GIF/交互能力等平台动态要求，在投放任务中查证，按需使用兼容性技能。

## 分项判定，不以总分抵消缺陷

| 维度 | 查看/测量 | 不通过的典型表现 |
| --- | --- | --- |
| 内容完整正确 | 对照原文、数字、名称、Logo、二维码及顺序 | 漏文、错字、虚构事实、二维码不可用 |
| 阅读与层级 | 实际显示尺寸、首要信息、读取顺序 | 放大才能读、装饰压住关键事实、层级争抢 |
| 视觉语言 | 比较参考与衍生部件的形线色材质空间 | 只同色、框体/图标串风格、擅改主参考 |
| 构图与节奏 | 全篇缩览和逐段查看、密度、对齐、留白 | 卡片重复到底、持续拥挤、空洞、重点失衡 |
| 局部完成度 | 细节、裁切、连接、字距、边缘与清晰度 | 接缝、拉伸、模糊、碰字、误裁、残余占位 |
| 交付有效性 | 打开文件、源层可改、检查版本与导出一致 | 缺图/字体、源图不一致、无效链接、未渲染却称通过 |

内容错误、正文无法正常阅读、遮挡/溢出、关键资产缺失、破坏明确风格约束为交付阻断项。视觉语言或构图明显失败也须修正，技术通过不抵消。方向审稿可以交待审版本，须正确标明用途与缺陷。

普通文字 4.5:1、大字 3:1 可作为对比度辅助筛查基线（借鉴已核查的 Impeccable 检查项）。纹理和图像底必须另看最差局部；采样数值不能作为整个栅格作品的无障碍认证。

## 看图与报告

查看同一版本的全篇缩览、阅读尺寸连续局部、关键细节。只看缩略全图不能判断正文清楚；可批量生成视图减少操作。

问题记录用“位置/截图 → 可见现象 → 阅读影响 → 修改 → 复查结果”。状态为通过、需修复、未检查、不适用；不用无依据的 95 分表达可靠性。

自动检查适合尺寸、溢出、字体/素材加载、文本保留、切片尺寸和文件可打开；视觉复核适合第一眼重心、主体关系、风格、密度和延展自然程度。

在项目证据记录中分别保留六项状态与视图：内容、绘法、图形延展、整体构图、阅读、技术交付。每条证据写出“参考/成图位置 → 可见做法或偏离 → 对应规则 → 判定”，避免“统一、细腻、完整”等单独结论。生成资产的提示词与参考用于排查来源，成品局部用于判断实际是否实现；两类证据分别保留。

风格有偏离时区分未落实约束、模型输出偏离和审查放行；看不到提示词或传图记录就保留不确定性。多位审查者都放行仍须核对关键证据，用户对明确审美约束的否决优先于内部评分。把失败译成可迁移的制作机制，不累积“永远禁用框/换底/大插图”等与问题无关的禁令。

批量修复后查看修改项和邻接；重大问题继续定向修复或如实报告工具/授权阻碍。通过后结束，没有新证据不追加润色。
