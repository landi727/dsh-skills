# 视觉作品想法梳理与图像生成提示词设计（Visual Brief）

定位：把"想做什么"变成一份**模型无关的简报**。四件事：**Visual Intent**（意图澄清）→ **Visual Constraints**（领域规范 + 去 AI 味）→ **Reference Translation**（参考翻译成锚点）→ **Brief**（13 字段简报）。

边界：**不做模型语法**——Midjourney / DALL·E / 即梦等的最终提示词由 `model-adapter` 负责；需求体检由 `no-slacking`、满意标准由 `im-satisfied` 负责。视觉类任务按 no-slacking → im-satisfied → 本 skill → model-adapter 接力。

## V1 · Visual Intent（意图澄清）

体检已由 no-slacking 做过，这里只问**视觉专属**问题，分级提问：

### 第一轮（最多 7 问）
1. **用途/载体**：App 图标 / 网页首屏 / 海报 / 社媒卡片 / 印刷 / 包装…
2. **类别**：插画 / 平面海报 / 网页 UI / App UI / 图标 / Logo-VI / 写实摄影 / 其他
3. **主体/主题**：画面里具体有什么？
4. **受众与语境**：给谁看、什么品牌调性？
5. **情绪/氛围**：第一眼感受到什么？
6. **风格方向**：扁平/手绘/写实/3D/复古/日式/赛博朋克…有参考图就描述参考图
7. **硬性约束**：尺寸比例、品牌色、必出现的文字、必避免的元素

### 第二轮按类别深挖
用 V2 中对应类别的问题清单继续。**快问快答模式**：用户只想快速要图时，按"用途+主题+风格"三要素直接出简报，不拖成问卷。

## V2 · Visual Constraints（类别规范 + 去 AI 味）

### 六类规范库
（每类：要澄清的要点 / 规范与生产约束 / 生产流程提示 / 常见坑）

#### 2.1 插画 / 平面海报
- **澄清**：叙事、风格（手绘/矢量/版画/3D）、色彩倾向、构图焦点、文字排版、用途（封面/内页/宣传）。
- **规范**：明确"画的媒介"（水彩/钢笔/risograph/丝网印刷/厚涂/扁平）比"插画风"有效；构图有焦点与动线；文字尽量少（模型易乱码）；3–5 色限定色板。
- **生产流程**：缩略草图→线稿→明度色稿→成稿；确认要**成稿**还是**线稿感**；海报分清**电子竖版/印刷横版**（印刷留出血）。
- **坑**：元素堆满无焦点、配色花哨、文字乱码、风格像"流行插画平均"。

#### 2.2 网页 / App UI
- **澄清**：整页 or 组件？桌面 or 移动？产品类型？品牌色/字体？**线框 / 高保真 mockup / 营销展示图**？暗色 or 亮色？
- **规范**：网格间距系统（如 8pt 栅格）；组件层级（导航/标题/正文/按钮/卡片/状态）字号字重对比成立；色彩系统（主色/辅色/中性/语义色）对比度达标；风格语言（毛玻璃/新拟态/极简…圆角阴影描边习惯）。
- **生产流程**：线框→设计系统→组件→状态/响应式→高保真。三种产物对提示词要求完全不同。
- **坑**：画成"好看插画"而非可用界面、文字数字乱码、控件不对齐。

#### 2.3 图标 Icon
- **澄清**：单图标 or 一套？线性/面性/双色/3D/毛玻璃？使用尺寸（16/24/32/48px）？与现有图标库一致？
- **规范**：固定网格内光学对齐，描边/圆角统一（如 2px）；一套图标同风格同描边同视觉重量；小尺寸可辨认。
- **生产流程**：草图→矢量路径→网格对齐→一致性检查。明确**单图标特写**还是**整套矩阵展示**。
- **坑**：描边粗细不一、透视混乱、细节过多看不清。

#### 2.4 Logo / 品牌 VI
- **澄清**：品牌名/缩写、行业、气质、图形标/字标/组合标、单色版/全色版、使用场景。
- **规范**：可缩放（16px favicon 到招牌都成立）；单色可用（去色仍能识别）；安全间距（clear space）；风格（极简几何/字母组合/徽章/复古/负空间/渐变）。
- **生产流程**：手绘概念→矢量化→网格对齐→单色反白测试→应用规范。明确**单个标志**还是**VI 展板**。
- **坑**：细节缩成糊、文字乱码、依赖渐变单色失效、像照片不像矢量。

#### 2.5 写实摄影
- **澄清**：主体、用途（广告/社媒/编辑）、风格（棚拍/街拍/胶片/精修）。
- **规范**（用拍摄语言）：镜头焦距（24/35/50/85/135mm）、光圈（f/1.4–f/16）、光线方向性质（侧光/逆光/柔光箱/窗光/黄金时刻）、胶片调色（Portra 400/Kodak Gold/白平衡）、机位视角。
- **生产流程**：布光→构图→拍摄→后期。明确**抓拍/摆拍、直出/精修**；主动加真实感锚点（颗粒/景深/环境光/不完美细节）。
- **坑**：塑料皮肤、滥用浅景深、HDR 廉价光、居中无张力。

#### 2.6 其他/混合
判定最接近的类别套用规范，再补特殊约束；混合需求分层描述（先定主体类别，次要元素作为"画面中的物件"）。

### 去 AI 味（内容知识；语法表达归 model-adapter）

**AI 味清单（逐条决定要不要禁）**
- 材质/色彩：塑料感/光滑 3D 渲染、磨皮蜡像皮肤、过饱和糖果色、青橙/紫橙渐变、廉价 HDR、体积光/霓虹光晕
- 构图：主体悬浮居中、完美对称、滥用浅景深 bokeh、元素平均堆细节
- 内容：空泛形容词堆砌（masterpiece/8k/cinematic）、空洞眼神完美微笑脸、文字手部崩坏、"概念图"而非"成品"
- 风格：无来源的"流行风格平均"、默认模型味

**正向锚点（去 AI 味六法）**
1. 锚定具体媒介/年代/流派（risograph print, 1970s Polish poster / Swiss Style / gouache children's book / 35mm Kodak Portra 400）
2. 用拍摄语言（50mm, f/2.8, 左侧窗光, slight film grain）
3. 主动要"不完美"（film grain, paper texture, hand-drawn imperfections, scanned print）
4. 构图打破居中（rule of thirds, off-center, asymmetric, cropped at edge）
5. 限色板（limited palette, 3–5 colors 或具体色值）
6. 留白（generous negative space）

## V3 · Reference Translation（参考 → 锚点）

- 用户给的参考图/风格词/口头描述 → 翻译成**具体可执行**的风格锚点（媒介/年代/流派/镜头语言），写进简报"风格与锚点"与"参考锚点"字段。
- 模糊词翻译对照：高级感 → 具体媒介 + 克制配色；治愈系 → 低饱和暖色 + 留白 + 手绘不完美；赛博朋克 → 霓虹青品红 + 雨夜 + 密集信息。

## V4 · Brief（模型无关简报，13 字段）

1. **一句话目标**：这张图要达成什么。
2. **类别 + 规格**：类别；尺寸/比例；用途载体。
3. **主体/主题**：画面里具体是什么，谁在做什么。
4. **风格与锚点**：风格方向 + 具体媒介/年代/流派锚点（见 V3）。
5. **构图**：焦点、视角、留白、元素主次。
6. **色彩**：主色/辅色/中性色，色板或具体色值。
7. **光照**：方向、性质、氛围。
8. **材质/纹理**：表面质感、颗粒、手作感。
9. **情绪**：第一眼感受 + 语气。
10. **必含元素**。
11. **禁含元素**（含 AI 味负向清单）。
12. **技术规格**：分辨率、是否含文字、留白/出血。
13. **参考锚点**：用户关键词/参考图描述，固定防漂移。

缺失项标注"假设：…"。**简报不含任何模型参数**（--ar/--v/采样器…那些是 model-adapter 的事）。

### 示例（简报形态：冥想 App 图标）
- 一句话目标：安静、可信的冥想 App 图标。
- 类别+规格：图标，1:1，App 图标/社媒头像。
- 主体：一朵莲花符号。
- 风格与锚点：扁平矢量、极简几何（Swiss Style 式克制）。
- 构图：居中 + 大量负空间。
- 色彩：深青绿描边 + 暖米白底。
- 情绪：平静、克制。
- 必含：莲花；禁含：渐变、3D、文字、装饰、AI 味（发光/塑料感）。
- 技术规格：小尺寸可读，纯色可缩放。
- → 下一步：交给 model-adapter 转 Midjourney / DALL·E 提示词。

## 视觉自检清单（交付简报前核对）

- [ ] 主体/主题、风格、情绪与用户意图一致？
- [ ] 必含都在、禁含（含 AI 味项）已列全？
- [ ] 六类规范里对应的生产约束都覆盖了？
- [ ] 参考已翻译成具体锚点，没有"高级感/好看"这类空词？
- [ ] 简报没有混入模型参数？

## 链

- 上游：`no-slacking`（体检）→ `im-satisfied`（标准卡）
- 下游：简报完成 → `model-adapter` 按目标模型出最终提示词。
